# Halloween

Reference material and prompt libraries for Halloween and creature image/video work.

- `style/jteve-sobs-style-guide.md` — breakdown of the Jteve Sobs (@jtevesobs) look: luminous techno-mysticism, sacred geometry, false-color science imaging, structural glitch, beat-synced cuts.
- `prompts/pipeline-pack.md` — the working pack for the actual toolchain: ChatGPT stills, Kling / Grok / Gemini motion, Suno track, cut map. Start here.
- `prompts/halloween-slopcannon-prompts.md` — wider prompt library on the same skeleton.
- `reference/` — frames generated from the pack.
